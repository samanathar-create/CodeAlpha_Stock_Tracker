# CodeAlpha Stock Portfolio Tracker

## About the Project

The Stock Portfolio Tracker is a Python project developed for the CodeAlpha Python Programming Internship. It helps users track stock investments by recording stock names, quantities, purchase prices, and investment values.

## Features

* Add stock investments.
* Record stock quantities and purchase prices.
* Calculate investment costs.
* Display portfolio information.
* Organize investment data.

## Technologies Used

* Python 3

## How to Run

1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python stock_tracker.py
```

## Purpose

This project demonstrates Python programming concepts, including variables, calculations, conditional statements, and data handling.
